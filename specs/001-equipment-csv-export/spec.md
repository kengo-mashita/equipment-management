# Feature Specification: 備品一覧のCSVエクスポート

**Feature Branch**: `feature/csv-export`

**Created**: 2026-10-03

**Status**: Draft

**Input**: User description: "docs/csv-export-request.md（備品一覧画面に「CSVダウンロード」ボタンを設置し、
今画面に表示されている備品の情報をCSVファイルとしてダウンロードできるようにする。棚卸しでのExcel集計や
他部署への共有に使う。シンプルな実装で、使いやすい形式とする。データは少量のため性能は考慮不要）"

## Clarifications

### Session 2026-10-03

- Q: CSVに「借用者」（貸出中の備品を現在借りている社員の氏名）の列を含めるか？ → A: 含める（ADMIN・USER共通）
- Q: CSVファイルの文字コードはどれにするか？ → A: BOM付きUTF-8
- Q: 検索欄の入力を書き換えたまま検索せずにダウンロードした場合、どの条件で出力するか？ → A: 最後に検索を実行した条件（＝現在表示中の一覧）で出力し、未実行の入力は無視する
- Q: 「貸出中」の備品の返却予定日（一覧画面には非表示）もCSVに出力するか？ → A: 出力しない（画面と同じ6列のみ）

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 備品一覧をCSVでダウンロードする (Priority: P1)

現場の担当者（管理者・一般ユーザー）が備品一覧画面を開き、「CSVダウンロード」ボタンを押すと、
一覧に表示されている全備品の情報がCSVファイルとして手元に保存される。担当者はそのファイルを
表計算ソフトで開き、棚卸しの集計や他部署への共有に使う。

**Why this priority**: 依頼の中核であり、これだけで「備品一覧をExcelで集計・共有したい」という
要望を満たせる最小の価値単位であるため。

**Independent Test**: 検索条件を指定せずに備品一覧画面を開き、ボタンを押してダウンロードしたファイルを
表計算ソフトで開くと、画面に表示されている全備品が文字化けなく1行1件で並んでいることを確認できる。

**Acceptance Scenarios**:

1. **Given** 管理者または一般ユーザーとしてログインし、検索条件なしで備品一覧画面を表示している、
   **When** 「CSVダウンロード」ボタンを押す、
   **Then** 画面に表示されている全備品が、見出し行付きのCSVファイルとしてダウンロードされる。
2. **Given** ダウンロードしたCSVファイルがある、
   **When** 表計算ソフト（Excel）でファイルをダブルクリックして開く、
   **Then** 日本語（品名・保管場所・状態・借用者名）が文字化けせず、各項目が別々の列に表示される。
3. **Given** 「貸出中」の備品が含まれている、
   **When** CSVをダウンロードする、
   **Then** その備品の行に、画面と同じく現在の借用者名が出力される。
4. **Given** 未ログイン状態である、
   **When** CSVダウンロードのURLに直接アクセスする、
   **Then** ファイルはダウンロードされず、ログイン画面に誘導される。

---

### User Story 2 - 絞り込んだ結果だけをCSVでダウンロードする (Priority: P2)

担当者が品名・状態で一覧を絞り込んだ状態で「CSVダウンロード」ボタンを押すと、
絞り込み後に画面に表示されている備品だけがCSVに出力される。
例えば「故障中」の備品だけを抽出して修理担当部署に共有できる。

**Why this priority**: 依頼の「今画面に表示されている備品の情報を出力してほしい」を満たすために必要だが、
全件出力（P1）だけでも基本的な棚卸し用途は成立するため。

**Independent Test**: 状態「故障中」で絞り込んだ後にダウンロードし、CSVの行が画面の一覧と
件数・内容とも一致することを確認できる。

**Acceptance Scenarios**:

1. **Given** 品名に「PC」を入力して検索し、一覧が絞り込まれている、
   **When** 「CSVダウンロード」ボタンを押す、
   **Then** 画面に表示されている備品（品名に「PC」を含むもの）だけがCSVに出力される。
2. **Given** 状態「故障中」で絞り込んでいる、
   **When** 「CSVダウンロード」ボタンを押す、
   **Then** 状態が「故障中」の備品だけがCSVに出力される。
3. **Given** 品名と状態の両方で絞り込んでいる、
   **When** 「CSVダウンロード」ボタンを押す、
   **Then** 両方の条件を満たす備品だけが、画面と同じ並び順でCSVに出力される。
4. **Given** 絞り込みの結果が0件である、
   **When** 「CSVダウンロード」ボタンを押す、
   **Then** 見出し行のみのCSVファイルがダウンロードされる（エラーにはならない）。

---

### Edge Cases

- 品名・保管場所などにカンマ、ダブルクォート、改行が含まれる場合でも、表計算ソフトで開いたときに
  列がずれず、値がそのまま1つのセルに表示されること。
- 検索欄の入力を書き換えたが「検索」を押さずに「CSVダウンロード」を押した場合、書き換えた値は無視し、
  画面に表示中の一覧（最後に検索を実行した条件）の内容を出力すること。
- 任意項目（保管場所・購入日）が未入力の備品は、該当列を空欄として出力すること。
- 「貸出中」以外の備品では借用者列は空欄とすること。
- 画面表示後に他の操作で備品データが変わった場合、CSVはダウンロード時点のデータを、
  画面と同じ検索条件で出力する（画面表示時点のスナップショットではない）。
- 不正な状態値など、一覧画面で受け付けない検索条件が指定された場合は、一覧画面と同じ扱いとし、
  システムエラー画面（スタックトレース）を表示しないこと。
- ブラウザ上の画面は遷移・変化せず、ファイルの保存のみが行われること。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: システムは、備品一覧画面に「CSVダウンロード」ボタンを表示しなければならない。
- **FR-002**: 「CSVダウンロード」ボタンは、管理者（ADMIN）・一般ユーザー（USER）の両方に表示され、
  両方が利用できなければならない。
- **FR-003**: ボタンを押すと、システムは備品一覧の情報をCSVファイルとしてダウンロードさせなければならない。
- **FR-004**: CSVに出力する備品は、現在表示中の一覧を得るために最後に実行された検索条件
  （品名の部分一致・状態）を適用した結果と一致し、並び順も一覧画面と同じでなければならない。
  検索欄に入力済みでも検索を実行していない値は、出力条件に使ってはならない。
- **FR-005**: CSVの1行目は見出し行とし、以下の列をこの順で出力しなければならない：
  品名、管理番号、保管場所、状態、購入日、借用者。これ以外の列（返却予定日など）は出力しない。
- **FR-006**: 状態は画面と同じ日本語表記（「利用可」「貸出中」「故障中」）で出力しなければならない。
- **FR-007**: 購入日は画面と同じ `YYYY-MM-DD` 形式で出力し、未入力の場合は空欄としなければならない。
- **FR-008**: 借用者列には、状態が「貸出中」の備品について現在の借用者の氏名を出力し、
  それ以外の備品では空欄としなければならない。
- **FR-009**: CSVファイルは、BOM付きUTF-8で出力しなければならない。これにより、日本語版Excel
  （Microsoft 365・2016以降）でファイルを直接開いたときに文字化けせず、機種依存文字も欠落しない。
- **FR-010**: 値にカンマ・ダブルクォート・改行が含まれる場合、CSVの一般的な規則（RFC 4180相当）に従って
  エスケープし、列がずれないようにしなければならない。
- **FR-011**: ダウンロードされるファイル名は、内容と取得日時が分かる名前
  （例：`equipment_20261003_153000.csv`）でなければならない。
- **FR-012**: 未ログインの利用者がCSVを取得しようとした場合、ファイルを返さずログイン画面へ誘導しなければならない。
- **FR-013**: 該当する備品が0件の場合、見出し行のみのCSVを出力しなければならない。

### Key Entities *(include if feature involves data)*

- **備品（Equipment）**: CSVの1行に対応する。品名・管理番号・保管場所・状態・購入日を出力する。既存のエンティティであり、本機能で項目の追加・変更はしない。
- **貸出記録（Lending）・社員（Employee）**: 「貸出中」の備品について、未返却の貸出記録に紐づく社員の氏名を借用者として出力するために参照する。本機能で変更はしない。
- **CSVファイル**: 永続化しない出力物。見出し行＋備品1件につき1行で構成される。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 担当者は備品一覧画面から1回のボタン操作で、表示中の備品一覧をファイルとして取得できる。
- **SC-002**: ダウンロードしたファイルを日本語版Excelでダブルクリックして開いたとき、追加の変換操作なしに
  全項目が文字化け・列ずれなく表示される（サンプルデータ全件で確認）。
- **SC-003**: 任意の検索条件の組み合わせ（条件なし／品名のみ／状態のみ／両方）において、
  CSVの行数と各行の内容が画面の一覧表示と100%一致する。
- **SC-004**: 一般ユーザー・管理者のどちらでもダウンロードでき、未ログインでは取得できないことが確認できる。
- **SC-005**: 想定データ量（数十件程度）で、ボタン押下から保存開始まで利用者が待たされる体感がない（数秒以内）。

## Assumptions

- 「今画面に表示されている備品」とは、一覧画面で現在適用されている検索条件（品名・状態）での検索結果全件を指す。
  ページネーションは存在しないため、ページ単位の考慮は不要。
- 出力列は一覧画面に表示されている情報（品名・管理番号・保管場所・状態・購入日・借用者）とする。
  一覧画面に表示されていない項目（返却予定日、登録日時・更新日時、内部ID）は出力しない。
- 借用者名は一覧画面で既に両ロールに表示されている情報であるため、CSVにもロールを問わず出力する
  （Clarifications 2026-10-03 で確定）。CSVファイルの他部署への共有可否は利用者側の運用に委ねる。
- 「使いやすい形式」は、日本語版Excelでダブルクリックするだけで正しく開けることを指すと解釈する。
- 出力は備品一覧のみを対象とし、貸出履歴・社員一覧のCSV出力、CSVインポートは対象外とする。
- 出力件数は数十件程度を想定し、大量データ向けの分割出力や非同期処理は行わない。
- 既存の認証・権限の仕組みと、一覧画面の検索機能をそのまま利用する。
