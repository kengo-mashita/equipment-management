# Contract: 備品一覧CSVダウンロード

**Feature**: [spec.md](../spec.md) | **Data Model**: [data-model.md](../data-model.md)

本機能が外部（ブラウザ・利用者）に公開するインターフェースは、HTTP エンドポイント 1 つ、
一覧画面の UI 要素 1 つ、および出力される CSV ファイルの形式である。

---

## 1. HTTP エンドポイント

### `GET /equipment/csv`

| 項目 | 内容 |
|---|---|
| 認証 | 必須（フォームログイン） |
| 認可 | `ROLE_ADMIN`・`ROLE_USER` の両方（FR-002） |
| CSRF | 対象外（GET・状態変更なし） |
| 副作用 | なし（読み取りのみ） |

#### リクエストパラメータ（クエリ文字列）

| 名前 | 必須 | 形式 | 意味 |
|---|---|---|---|
| `name` | 任意 | 文字列 | 品名の部分一致。未指定・空文字は条件なし |
| `status` | 任意 | `AVAILABLE` / `LENT` / `BROKEN` | 状態の完全一致。未指定・空文字は条件なし |

一覧画面 `GET /equipment` と同じパラメータ名・同じ意味である（FR-004）。

#### レスポンス

**(a) 成功 — `200 OK`**

| ヘッダー | 値 |
|---|---|
| `Content-Type` | `text/csv;charset=UTF-8` |
| `Content-Disposition` | `attachment; filename="equipment_yyyyMMdd_HHmmss.csv"`（リクエスト処理時点のサーバーローカル日時。例：`equipment_20260923_143015.csv`） |

本文：[3. CSVファイル形式](#3-csvファイル形式) に従うバイト列。対象 0 件でも `200 OK` で列見出し行のみを返す（FR-015）。

**(b) 未ログイン — `302 Found`**

`Location` はログイン画面（`/login`）。CSV は返さない（FR-014）。

**(c) 不正な検索条件 — `302 Found`**

`status` が空でなく、上表の 3 値のいずれにも一致しない場合（例：`status=UNKNOWN`、`status=available`）。

- `Location: /equipment`（検索条件は付けない）
- フラッシュ属性 `error` = `検索条件が不正です。条件を指定し直してください。`
- 一覧画面の既存のエラー表示領域（`alert--error`）に表示される（FR-017）

**(d) 想定外エラー — `302 Found`**

CSV 組み立て中に想定外の例外が発生した場合。

- `Location: /equipment`
- フラッシュ属性 `error` = `CSVファイルの出力中にエラーが発生しました。時間をおいて再度お試しください。`
- サーバーログに ERROR レベルで原因例外（スタックトレース付き）を出力。画面にはスタックトレースを出さない（FR-016）

## 2. UI 要素（備品一覧画面 `templates/equipment/list.html`）

| 項目 | 内容 |
|---|---|
| 要素 | `<a class="btn btn--secondary">CSVダウンロード</a>`（JavaScript 不使用） |
| 配置 | ページヘッダーの操作領域（`page-actions`）。**ADMIN・USER の両方に表示**する（既存の「＋ 新規登録」は ADMIN のみのまま） |
| リンク先 | `@{/equipment/csv(name=${name},status=${status})}` — 一覧に**現在適用されている**検索条件を引き継ぐ |
| 動作 | クリックでファイル保存が始まり、画面は一覧のまま遷移しない（FR-003） |

例：状態＝故障中で検索した一覧のリンクは `/equipment/csv?name=&status=BROKEN` 相当になる
（null / 空の条件の出力形はThymeleafに従い、いずれもサーバー側で「条件なし」と解釈される）。

## 3. CSVファイル形式

| 項目 | 規定 |
|---|---|
| 文字コード | UTF-8。先頭 3 バイトは BOM `EF BB BF`（FR-010） |
| 行区切り | CRLF。最終行の末尾にも CRLF |
| 列区切り | `,` |
| 1 行目（列見出し） | `品名,管理番号,保管場所,状態,購入日,借用者`（FR-006） |
| 2 行目以降 | 備品 1 件 = 1 行。並び順は同条件の一覧画面と同一（ID 昇順、FR-005） |

### 列定義

| # | 見出し | 値 | 空欄になる条件 |
|---|---|---|---|
| 1 | 品名 | 備品の品名 | なし |
| 2 | 管理番号 | 備品の管理番号 | なし |
| 3 | 保管場所 | 備品の保管場所 | 未登録（FR-008） |
| 4 | 状態 | `利用可` / `貸出中` / `故障中`（FR-007） | なし |
| 5 | 購入日 | `yyyy-MM-dd`（FR-008） | 未登録 |
| 6 | 借用者 | 現在の借用者（社員）の氏名（FR-009） | 状態が `貸出中` 以外 |

### フィールド整形

1. 列 1・2・3・6 の値が `=`、`+`、`-`、`@` で始まる場合、先頭に `'` を付ける（FR-012）。
2. 値にカンマ・ダブルクォート・CR・LF が含まれる場合、`"` を `""` に置換し値全体を `"` で囲む（FR-011）。

入出力例は [data-model.md の整形ルール表](../data-model.md#フィールド整形ルールcsvformatter適用順) を参照。

### 出力例（BOM・CRLF は不可視）

```text
品名,管理番号,保管場所,状態,購入日,借用者
ノートPC,EQ-0001,会議室A,貸出中,2024-04-01,山田 太郎
"プロジェクター, 4K",EQ-0002,,利用可,,
'-20℃用冷蔵庫,EQ-0003,"倉庫""B""",故障中,2023-12-15,
```
