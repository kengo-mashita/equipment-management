# Quickstart: 備品一覧のCSVエクスポートの動作確認

**Feature**: [spec.md](./spec.md) | **Contract**: [contracts/csv-download.md](./contracts/csv-download.md)

## 前提

- WSL上にJDK 21があること（追加インストール不要）
- プロジェクトルートで作業する

## 1. 自動テスト

```bash
./mvnw test
```

期待結果：全テストが成功する。特に以下が含まれていること。

- `EquipmentCsvExportService` の単体テスト（列順・状態ラベル・借用者・空欄・エスケープ・BOM・CRLF・0件）
- CSVダウンロードの結合テスト（ADMIN/USERで200、未ログインで `/login` へリダイレクト、
  検索条件の反映、不正な状態値でのリダイレクト、ヘッダーとファイル名）

## 2. アプリでの確認

```bash
./mvnw spring-boot:run
```

ブラウザで `http://localhost:8080` にアクセスする。

| # | 操作 | 期待結果 | 対応 |
|---|---|---|---|
| 1 | `user` / `user123` でログインし、備品一覧の「CSVダウンロード」を押す | `equipment_YYYYMMDD_HHmmss.csv` が保存され、画面は遷移しない | US1, FR-001〜003, FR-011 |
| 2 | 1のファイルを日本語版Excelでダブルクリックして開く | 6列（品名〜借用者）が文字化け・列ずれなく表示され、件数が画面の「全 N 件」と一致 | US1, SC-002 |
| 3 | 2で「貸出中」の行を確認 | 借用者列に画面と同じ氏名が出ている。他の状態の行は空欄 | FR-008 |
| 4 | 状態「故障中」で検索してからダウンロード | 故障中の備品だけが出力される | US2, FR-004 |
| 5 | 品名欄を書き換え、「検索」を押さずにダウンロード | 書き換え前（表示中）の一覧と同じ内容が出力される | FR-004（Clarifications） |
| 6 | 一致しない品名で検索（0件）してダウンロード | 見出し行のみのファイルが得られる | FR-013 |
| 7 | `admin` / `admin123` で 1 を繰り返す | 同様にダウンロードできる | FR-002 |
| 8 | ログアウト後、`http://localhost:8080/equipment/csv` に直接アクセス | ログイン画面が表示される | FR-012 |
| 9 | ログイン後、`/equipment/csv?status=XXX` にアクセス | 備品一覧画面に「検索条件が不正です」が表示される | Edge Cases |
| 10 | 品名にカンマ・ダブルクォートを含む備品をADMINで登録し、ダウンロードしてExcelで開く | 値が1つのセルにそのまま表示される | FR-010 |

## 3. 片付け

確認用に登録した備品（手順10）は、ADMINで削除する。
