# 機能追加の依頼：備品一覧のCSVエクスポート

## 背景・要望

現場の担当者から、「備品一覧をCSVでダウンロードしたい」という要望が来ています。
棚卸しの際にExcelで集計したり、他部署に共有したりするのに使いたいとのことです。

備品一覧画面に、CSVをダウンロードできるボタンを追加してほしいです。

## やりたいこと

- 備品一覧画面に「CSVダウンロード」ボタンを設置する
- ボタンを押すと、備品データがCSVファイルとしてダウンロードされる
- 今画面に表示されている備品の情報を出力してほしい

## 補足

- できるだけ早く使いたいので、シンプルな実装でお願いします
- 使いやすい形式でお願いします
- 大量のデータではないので、パフォーマンスは気にしなくて大丈夫です
